Free Outlook signature pilot

Blueprint central signatures

The shared signature template is stored in this GitHub Pages repository. The add-in fills in the sender’s name and email locally in Outlook. No staff directory, passwords, or access tokens are stored here.

View the shared configuration

Edit the shared configuration (repository owner access required)

Publishing a template change updates fresh compose windows after GitHub Pages publishes it. Existing drafts and messages already sent are unchanged.

This pilot is limited through Microsoft 365 assignment and an additional hashed sender allowlist. It is not a mandatory send-time policy.
